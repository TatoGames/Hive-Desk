# ⬢ HiveDesk

> 처음이라면 [사용법 가이드](docs/guide.md)부터 읽어 보세요.

**내 PC에 설치된 AI 코딩 CLI 여러 개를 하나의 팀처럼 돌리는 데스크톱 앱.**
Claude Code · OpenAI Codex · Antigravity(agy)를 각자 **자기 계정(무료·구독)** 으로 연결해서
칸반 보드로 일을 나누고, 공유 메모리와 메시지함으로 서로 맥락을 넘기고, 위험한 작업은 사람이 승인해요.

> API 키를 쓰지 않아요. HiveDesk는 이미 로그인된 CLI를 대신 실행할 뿐이라 **추가 API 요금이 나가지 않아요.**

[Munder Difflin](https://github.com/HarnessMD/munder-difflin)의 아이디어에서 영감을 받아, 작은 팀이 쓰기 쉬운 크기로 새로 만든 프로젝트예요.

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| **여러 에이전트** | 에이전트마다 사용할 AI, 역할, 작업 폴더, 모델을 정해요. 한 사람이 여러 개를 둘 수 있어요. |
| **칸반 태스크 보드** | 할 일 → 승인 대기 → 실행 중 → 완료 / 실패. 선행 태스크를 지정하면 앞 태스크 결과가 다음 에이전트에게 넘어가요. |
| **자동 실행** | 켜 두면 내 에이전트에게 배정된 준비된 태스크를 차례로 실행해요 (동시 실행 수 제한). |
| **메시지함** | 사람이나 에이전트가 특정 에이전트에게 메시지를 남기면, 그 에이전트의 다음 실행 때 전달돼요. |
| **공유 메모리** | "패키지 매니저는 pnpm" 같은 팀 규칙을 적어 두면 모든 에이전트가 매번 함께 읽어요. 에이전트도 스스로 기록해요. |
| **승인 큐** | 위험 표시된 태스크, 예산 초과, 에이전트가 직접 멈추고 물어본 일은 사람이 승인/거절해요. |
| **실행 기록·변경 비교** | 실행마다 보낸 지시, 응답, 시간, 성공 여부가 덮어쓰이지 않고 남아요. 작업 폴더가 git 저장소면 실행 전후로 바뀐 파일과 diff를 보여줘요. 카드의 *기록·변경*에서 볼 수 있어요. |
| **실시간 활동 피드·진행** | 실행 중 AI가 하는 일(읽기·수정·명령·메시지)이 실시간으로 보이고, 경과 시간·단계 수·건드린 파일·바뀐 줄 수·계획 체크리스트(n/m)가 표시돼요. 작업 폴더 경로와 *폴더 열기* 버튼도 있어요. |
| **바뀐 파일 실시간 확인** | 피드는 AI가 스스로 알려 주는 내용이라, 작업 폴더를 3초마다 직접 비교한 실제 변경 목록을 나란히 보여줘요. 파일별 diff 보기, 기본 앱으로 열기를 지원해요. git이 아닌 폴더는 파일 목록만 보여주고, *변경 추적 켜기*로 git 저장소로 만들 수 있어요. |
| **자료 첨부·참고 폴더** | 파일·이미지를 끌어다 놓으면 작업공간의 태스크 폴더로 복사되고 경로가 프롬프트에 들어가요(팀 공유). 큰 파일은 설정한 크기(기본 5MB)를 넘으면 이 컴퓨터에만 둬요. 태스크마다 참고 폴더도 지정할 수 있어요. |
| **권한 단계** | 태스크마다 읽기만 / 작업 폴더 수정 / 명령 실행(위험, 승인 필요). 에이전트에 '기본 권한'을 정해 둘 수도 있어요. Claude·Codex는 CLI 옵션으로 실제로 막고, Antigravity·직접 지정은 기본이 '읽기만'이에요(수정을 맡기려면 실행 전 점검에서 '위험을 알고 있어요'를 체크). 기본 단계에서는 `rm`·`mv` 같은 삭제·이동 명령을 Claude에서 막아요. |
| **되돌리기** | 실행 전에 상태를 저장해 둬요(git 저장소는 숨은 참조, 아니면 파일 백업 — 파일 5000개·100MB 넘는 폴더는 백업 안 함). 태스크 상세·카드의 *되돌리기*로 그 실행이 바꾼 것만 원래대로 돌려요. |
| **폴더 잠금·한도 대기** | 같은 작업 폴더에서는 한 번에 한 태스크만 실행해요(나머지는 '폴더 대기'). CLI가 사용량 한도를 알리면 그 CLI의 자동 실행을 풀릴 때까지 멈추고(수동으로 *한도 해제* 가능) 태스크는 '할 일'로 남아요. |
| **앱 종료·절전 대응** | 실행 중에는 절전을 막고, 종료하려 하면 확인을 받아요. 실행 중 앱이 닫히면 다음에 켤 때 '중단됨'으로 표시하고 변경분을 보여 줘요. |
| **사람 확인 칸** | 설정의 *결과 확인*(기본: 파일이 바뀐 결과만)에 따라 완료 전에 '사람 확인' 칸에서 *확인했어요* / *수정 요청* / *되돌리기*를 해요. 확인 전에는 이 태스크를 기다리는 다음 태스크가 시작되지 않아요. |
| **민감 파일·첨부 안내·실패 설명** | `.env`·키 파일은 Claude의 읽기 도구로 못 열게 막고(셸 명령까지는 못 막아요), 엑셀·워드 같은 형식은 PDF/텍스트로 바꾸라고 안내해요. 실패는 로그인 만료·한도·권한·명령 없음·네트워크·무응답으로 나눠 한국어로 설명해요. 무응답 제한은 '아무 반응이 없는 시간' 기준이고, 총 시간 상한은 태스크별로(기본 240분) 둬요. |
| **프로젝트** | 팀이 함께 보는 작업 묶음. 고정 브리핑(항상 프롬프트에 들어감), 공용 폴더 이름 + 컴퓨터마다 따로 지정하는 실제 경로. 메모리는 '고정'(항상)과 '최근'으로 나뉘어 전달돼요. 선행 태스크의 정형 보고서가 잘린 결과 대신 전달돼요. |
| **팀 공유 보완** | 실행 요약(보고서·변경 파일·줄 수, 작은 패치·응답)이 공유 폴더에 올라가 팀원도 볼 수 있어요. 태스크를 손으로 고친 내용은 타임라인에 이벤트로 남아요. 에이전트 목록에 마지막 연결 확인 결과가 보이고, 최근 실패한 에이전트에 배정하면 경고해요. |
| **회사 모델** | 템플릿(게임 스튜디오·스타트업·웹 서비스 개발사·팀 프로젝트·빈 회사)으로 조직도(본부>실>팀>파트, 편집 가능)·직급·자리를 만들고, 자리마다 직무·체급에 맞는 모델을 추천해요. 에이전트는 직급·소속·직무·정확한 모델 버전(고정 또는 최신 따라가기)·기본 권한을 가져요. |
| **모델 카탈로그** | Claude(Fable 5.1·Opus 5.5·Sonnet 5.5·Haiku 5.5), OpenAI(GPT-6 Astra·6.1 Sol·6 Luna), Google(Gemini 3/2.5 Pro·Flash)이 들어 있고 직접 추가·수정할 수 있어요(`<설정 폴더>/models.json`을 고쳐도 반영). *사용 확인*으로 이 계정에서 그 모델이 실제로 되는지 확인해요. |
| **배치 규칙·적성 점수** | 팀 안 모델 2개 이상 / 검토자는 작업자와 다른(같거나 높은) 모델 / CEO는 서로 다른 모델 — 각각 켜고 끌 수 있고 어긋나면 조직도에 경고가 떠요. 모델 버전×직무별 통과율·수정 요청·시간을 쌓아 점수와 재배치 추천을 보여 줘요(태스크 3개 미만이면 '기록 부족'). |
| **새 버전 알림** | 앱을 켤 때 GitHub 릴리스를 확인해 새 버전이 있으면 알려요(자동 설치는 아님). |
| **실행 전 점검** | 실행 누르면 폴더·첨부·권한·문제점을 확인하는 화면이 떠요. 참고 폴더가 없으면 경고해요. |
| **자료 요청·이어서 진행** | 에이전트가 `[[NEED: …]]`로 멈추면 '자료 요청' 상태가 되고, 답하면 같은 대화로 이어가요. 실행 중 추가 지시는 현재 단계가 끝난 뒤 반영돼요. 언제든 중지할 수 있고 바뀐 파일 목록은 남아요. |
| **정형 보고·타임라인** | 에이전트가 한 일 / 바꾼 파일 / 확인 방법 / 남은 위험 / 다음 할 일 형식으로 보고하고, 태스크마다 생성 → 결재 → 실행 → 결과 타임라인이 남아요. |
| **예산 제한** | 에이전트별 하루 실행 횟수·실행 시간·1회 제한 시간. 구독 사용량을 순식간에 다 써 버리는 걸 막아요. |
| **팀 공유 (선택)** | 작업공간을 GitHub 비공개 저장소로 동기화하면 팀원끼리 같은 보드를 봐요. 서버가 필요 없어요. |

### 조직에 위임 (3단계)
- 새 태스크에서 **조직에 위임**을 켜면 총괄 본부장(또는 고른 부서의 장)이 일을 나누고, 담당자가 하고, **다른 모델이 교차 검토**한 뒤, 상위 관리자가 통합해 **최종 보고서**로 올라와요. 보고서는 **보고서함**에서 확인·마크다운으로 내보내요.
- 큰 일(예상 AI 실행 횟수가 기준 초과, 위험·범위 확대·타 부서·기존 결정 충돌·프로젝트 예산 초과, 내가 직접 지정한 관리자의 첫 계획)은 **이사회(나)의 계획 결재**를 받아요. 나머지는 윗사람이 승인해요.
- 교차 검토에서 수정 요청이 2번 쌓이면 윗 직책이 넘겨받고, 그래도 막히면 나에게 와요.

### CEO 위원회·성과·알림 (4단계)
- **CEO 위원회**: CEO 자리 에이전트들이 각자 제안 → 한 번 서로 비판 → 이유와 함께 투표 → 추천과 소수 의견을 보고, 내가 결정해요. 결정은 고정 메모리로 저장돼요. 관리자가 방향을 못 정하면 `[[ESCALATE: …]]`로 위원회에 올려요.
- **성과**: 에이전트·팀·모델별 업무/완료/실패/수정 요청과 모델 한도 사용량. 회사 탭의 재배치 추천에는 **적용** 버튼이 있어요.
- **데스크톱 알림**: 승인·자료 요청·결과 확인·실패·보고서가 생기면 알려줘요 (설정에서 끌 수 있어요).

### 여러 회사·AI 연결·오피스·회사 간 협업 (v3)
- **여러 회사**: 회사마다 폴더·git 저장소·조직·메모리·직원이 완전히 분리돼요. 왼쪽 위 전환기로 바꾸고, `이사회` 탭에서 모든 회사의 대기 항목을 한눈에 봐요. v0.2 작업 공간은 백업을 만든 뒤 첫 번째 회사로 자동 옮겨져요.
- **AI 연결 → 모델 에이전트 → 직원**: 연결(프로그램+내 계정)이 확인되면 쓸 수 있는 모델마다 모델 에이전트가 생기고, `채용`하면 그 회사의 직원이 돼요. 추천 자동 연결(미리보기 표)과 직접 끌어다 놓기를 모두 지원해요. 계정 한도는 회사별 우선순위로 나눠 써요.
- **오피스**: 직원 카드(상태 색·진행률), 업무 흐름선, 분해 트리, 소식판, 업무 맡기기. 목록 보기도 그대로 있어요.
- **회사 간 협업(허가 기반)**: 기본은 모두 꺼짐. 이사회가 채널(무엇을·방향·권한·기간)을 열어야만 **복사본+출처**가 상대 회사의 외부 자료함에 들어가고, 업무 의뢰는 상대 보드에서 일반 위임 규칙으로 처리돼 결과가 돌아와요. AI가 `[[COLLAB: 대상 | 필요한 것 | 이유]]`로 요청하면 이사회 결재함에 올라오고 회사는 사용자가 골라요. 채널을 닫으면 복사본은 "회수됨"으로 표시되고 AI에게 더는 전달되지 않아요. 모든 이동(막힌 시도 포함)은 감사 기록에 남아요.
### 멈춤·빠른 배정·실시간 조정 (v4)
- **중지는 중지예요**: ⏸ 중지하면 업무가 `보류`가 되고, 이어서 하기를 누르기 전에는 저절로 다시 시작하지 않아요. ✕ 취소는 아래 업무까지 범위를 보여 주고, 파일을 되돌릴지 매번 물어요. 비상 정지(트레이 메뉴 포함)는 모든 회사의 실행을 멈춰요. 멈출 때는 SIGTERM, 5초 뒤에도 안 끝나면 강제 종료해요.
- **실행 중 조정(Claude Code)**: 업무가 도는 동안 지시를 바로 전달(`바로 반영`), 하던 단계를 끊고 전달(`즉시 끊고`), 끝난 뒤 전달(`끝난 뒤`) 중에서 골라요. ⏯ 일시 정지하면 대화를 유지한 채 멈추고 `지시하고 이어서`로 이어가요. 지시는 `대기→전달→확인→반영`으로 추적돼요. Codex 등은 끊고 → 진행 요약과 함께 다시 시작하는 방식으로 대신해요. 설정에서 예전 방식(끝난 뒤에만 반영)으로 되돌릴 수 있어요.
- **위임 중 조정**: 위임 업무에는 `아래 업무에도 전달`, `다시 계획`, 단계 건너뛰기·더하기가 있어요.
- **빠른 배정·속도**: 가벼운 일은 이력으로 가장 알맞은 직원에게 바로 배정하고(위원회 한 라운드), 별도 작업 폴더(git 작업 트리)에서 하위 작업을 동시에 실행하고(실험), 손대지 않은 묶음은 다시 시작하기 전에 물어요.
- **결재 자동화**: 읽기 → 파일 수정 올림, 소폭 초과 계획, 더 작아진 재제출 계획은 자동 승인(기록에 `자동`). 삭제·배포·외부 전송·명령 실행은 절대 자동 승인하지 않아요. 결재가 오래 쌓이면 기본 처리하고, Discord/Telegram으로 알림을 받을 수 있어요.
- **사용량 보이기·실행 중 메시지**: 추천 자동 연결 표에 자리마다 사용량 가중치와 합계가 나오고, [가벼운 모델로] 버튼으로 바로 바꿀 수 있어요. 실행 중인 Claude 직원에게 보낸 메시지는 다음 실행을 기다리지 않고 바로 전달돼요.

### 외부 연결: 웹 · GitHub · 다른 앱(MCP) (v4)
- **기본은 꺼짐, 회사별, 직원별**: `외부 연결` 탭에서 연결을 만들어도 직원(또는 직급)에게 `읽기 / 쓰기(결재) / 쓰기(자동)`을 주기 전에는 아무도 못 써요. 다른 회사의 AI에게는 보이지도 않아요.
- **실시간 결재**: AI가 외부에 쓰려 하면(또는 허용 목록 밖의 사이트를 읽으려 하면) 그 자리에서 실행이 멈추고 결재함에 보낼 내용 전체가 올라와요. [승인] [고쳐서 승인] [거절 + 이유]. 답이 없으면 30분 뒤 거절하고 AI는 하던 일을 계속해요. 웹을 읽은 실행에서는 `쓰기(자동)`도 결재로 바뀌어요(웹페이지의 숨은 지시 방지).
- **웹(읽기만)**: 웹 검색과 허용 사이트 읽기. 업무에 주소를 붙이면 앱이 직접 읽어 글만 첨부해서 어떤 AI든 볼 수 있어요. 읽은 주소는 보고서의 `참고한 출처`에 남고 [메모리로 저장]할 수 있어요.
- **GitHub**: 외부 연결 탭의 [GitHub CLI 설치]로 gh를 바로 설치하고(Windows는 winget, macOS·Linux는 공식 릴리스를 `~/.local/bin`에 — 관리자 권한 불필요) [GitHub 로그인]으로 브라우저 로그인해요. 프로젝트에 저장소를 지정하면 업무가 `hive/업무-이름` 브랜치(별도 폴더)에서 돌고 끝날 때마다 보고서를 커밋 메시지로 커밋해요. 사람 확인을 통과하면 브랜치를 올리고 PR을 만들어요(설정으로 매번 결재도 가능). main에는 직접 올리지 않고, 머지는 CI가 통과한 뒤 사람이 눌러야 해요. 라벨 붙은 이슈 가져오기, 끝난 이슈에 댓글(결재), PR 리뷰 댓글 → 업무 지시, CI 실패 → [실패 고치기]. push와 gh는 AI에게 막아 둬요.
- **다른 앱(MCP)**: Notion·Slack·Linear(토큰), Figma(데스크톱 Dev Mode) 또는 직접 입력. [도구 목록 읽기]가 도구를 읽기/쓰기로 나눠요(읽기 전용 표시가 없으면 쓰기). 토큰은 이 컴퓨터의 OS 보안 저장소에만 두고 팀에는 "어떤 연결을 쓰는지"만 공유돼요. 실행할 때만 그 회사의 임시 MCP 설정을 만들고(`--strict-mcp-config`) 끝나면 지워요.
- **모두 기록**: 외부 연결로 읽고 쓴 것, 거절된 것까지 `외부 연결 → 기록`에 남아요. 외부에 한 일은 되돌리기로 되돌릴 수 없어서 실행 기록과 보고서에 따로 표시해요.
- 실제 AI 프로그램으로 확인할 목록: `docs/real-ai-checklist.md`

## 어떻게 동작하나요?

```
 [태스크 보드] ──배정──▶ [에이전트: 백엔드 (Claude Code)]
       ▲                         │  claude -p  ← 프롬프트(역할+태스크+메모리+메시지)를 stdin으로
       │                         ▼
   결과·메모리·메시지 ◀── 출력 파싱: [[MEMORY: …]] [[MSG to=…: …]] [[APPROVAL: …]]
```

- 작업공간(hive)은 평범한 폴더예요. 태스크·메시지·메모리·승인이 **항목당 JSON 파일 하나**로 저장돼서 git으로 합칠 때 충돌이 적어요.
- 에이전트는 실행할 때마다 역할, 태스크 내용, 선행 태스크 결과, 최근 공유 메모리, 안 읽은 메시지를 받아요.
- 에이전트가 답 끝에 아래 줄을 쓰면 HiveDesk가 알아서 처리해요.
  - `[[MEMORY: 팀이 기억할 사실]]` → 공유 메모리에 기록
  - `[[MSG to=팀원에이전트ID: 내용]]` → 그 에이전트의 메시지함으로
  - `[[APPROVAL: 이유]]` → 작업을 멈추고 승인 큐로
  - `[[NEED: 필요한 자료]]` → 작업을 멈추고 '자료 요청'으로 (답하면 같은 세션으로 이어서)
  - `[[PLAN: 할 일 1 | 할 일 2]]` `[[STEP: 번호]]` → 진행 체크리스트
  - `[[DID: …]]` `[[FILES: …]]` `[[VERIFY: …]]` `[[RISK: …]]` `[[NEXT: …]]` → 정형 보고서 (한 일 / 바꾼 파일 / 확인 방법 / 남은 위험 / 다음 할 일)
- 실행마다 `.local/runs/`에 활동 기록이 남고, 첨부는 `attachments/`(공유) 또는 `.local/attachments/`(큰 파일, 이 컴퓨터만)에 저장돼요.
- 타임라인(`events/`)은 팀과 공유되고, 실행 기록(지시·응답·diff)은 용량 때문에 실행한 컴퓨터의 `.local/runs/`에만 저장돼요.

## 설치

1. [Releases](https://github.com/TatoGames/Hive-Desk/releases)에서 운영체제에 맞는 파일을 받아요.
   - macOS: `.dmg` (Apple Silicon은 arm64, Intel은 x64)
   - Windows: `.exe`
   - Linux: `.AppImage`
2. 쓰고 싶은 AI CLI를 설치하고 로그인해요. **앱 안의 *AI 연결하기*에서 버튼으로 할 수 있어요.** 직접 하려면 아래 명령을 쓰세요.

| AI | 설치 | 로그인 (API 키 없이) |
|---|---|---|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` (Windows: `irm https://claude.ai/install.ps1 \| iex`) | `claude` 실행 → Claude Pro/Max 계정 로그인 |
| OpenAI Codex | `npm install -g --prefix ~/.npm-global @openai/codex` (관리자 암호 없이 설치) | `codex login` → *Sign in with ChatGPT* |
| Antigravity (agy) | `curl -fsSL https://antigravity.google/cli/install.sh \| bash` | `agy` 실행 → Google 계정 로그인 (무료 계정 가능) |
| 기타 | 직접 지정 | stdin으로 프롬프트를 받아 stdout으로 답하는 CLI면 무엇이든 (예: `ollama run llama3`) |

> 설치 후 터미널에서 `claude`를 못 찾는다고 나와도 괜찮아요. HiveDesk는 `~/.local/bin`, `~/.npm-global/bin`, Homebrew, nvm 폴더를 알아서 찾아요.
> 앱이 열려 있는 동안 설치했다면 에이전트 탭의 *다시 확인*을 누르세요.

> **API 요금 방지:** 설정의 *API 키 환경변수 숨기기*(기본 켜짐)는 `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY` 등을
> CLI 실행 환경에서 빼서, CLI가 API 과금 대신 로그인한 계정을 쓰게 해요.
> Claude Code의 추가 인자에 `--bare`를 넣지 마세요. bare 모드는 구독 로그인을 무시해요.

### macOS에서 처음 열 때

아직 Apple 개발자 서명이 없어서 처음 한 번은 macOS가 확인을 요청해요. 터미널은 필요 없어요.

1. 응용 프로그램 폴더에서 HiveDesk를 열면 *"HiveDesk"을(를) 확인할 수 없습니다* 같은 창이 떠요. **완료**를 눌러 닫아요.
2. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 *"HiveDesk"이(가) 차단되었습니다* 옆 **그래도 열기**를 눌러요.
3. 암호나 Touch ID로 확인하면 열려요. 다음부터는 바로 열려요.

v0.1.1 이하 버전에서 *"손상되었기 때문에 열 수 없습니다"*가 뜨면 최신 버전을 받거나, 터미널에서 `xattr -cr /Applications/HiveDesk.app`을 한 번 실행하세요.

Windows에서 SmartScreen 경고가 뜨면 *추가 정보 → 실행*을 누르세요.

## 처음 사용하기

1. 앱을 열고 **이름**과 **작업공간 폴더**를 정해요.
2. **에이전트** 탭의 *AI 연결하기*에서 쓰고 싶은 AI 카드의 버튼을 차례로 눌러요.
   - **① 설치**: 공식 설치 명령을 앱이 대신 실행해요. 관리자 암호는 필요 없어요.
   - **② 로그인**: 터미널 창이 열리고 그 CLI의 로그인 화면이 떠요. 브라우저에서 계정으로 로그인하면 끝이에요. 처음 한 번만 하면 돼요.
   - **③ 연결 확인**: 잘 되면 그 AI로 에이전트가 자동으로 만들어져요.
3. **태스크 보드**에서 태스크를 만들고 담당 에이전트를 고른 뒤 *실행*하거나, *자동 실행*을 켜요.

에이전트의 역할(예: "Unity C# 게임플레이 담당")이나 작업 폴더(프로젝트 폴더)는 *수정*에서 바꿀 수 있어요.

### 권한 기본값

| AI | 기본 추가 인자 | 의미 |
|---|---|---|
| Claude Code | `--permission-mode acceptEdits` | 작업 폴더 안 파일 수정은 허용. 삭제·이동 명령(`rm`·`mv` 등)과 비밀 파일 읽기는 차단, 그 밖의 셸 명령은 거부 |
| Codex | `--sandbox workspace-write` | 작업 폴더 안에서만 쓰기 허용 |
| Antigravity / 직접 지정 | (없음) | HiveDesk가 막을 방법이 없어서 기본은 '읽기만'. 수정은 실행 전 점검에서 위험 확인 후 |

더 넓은 권한이 필요하면 에이전트 설정의 *추가 인자*에서 바꿀 수 있어요. 그럴 때는 *모든 태스크 실행 전 승인 받기*를 함께 켜 두는 걸 권해요.

## 팀으로 쓰기

각자 **자기 PC에서 자기 AI 계정**으로 에이전트를 돌리고, 보드·메시지·메모리만 GitHub 비공개 저장소로 공유해요.

1. 팀장이 GitHub에 **비공개** 저장소를 하나 만들어요 (예: `our-hive`). 팀원을 collaborator로 초대해요.
2. 각자 설정 → *팀 공유*에 같은 저장소 주소를 넣고 *공유 켜기* → *지금 동기화*.
   (PC에 git이 설치되어 있고, GitHub 로그인(credential)이 되어 있어야 해요.)
3. 이제 팀원의 에이전트가 담당자 목록에 보여요. 팀원 에이전트에게 배정한 태스크는 **그 팀원의 PC에서** 실행돼요.
4. *자동 동기화 간격*을 정하면 주기적으로 주고받아요.

공유되지 않는 것: 각자의 에이전트 설정(작업 폴더, 인자), AI 계정, 오늘 사용량(`.local/` 폴더).

두 사람이 같은 태스크를 동시에 고치면 충돌이 날 수 있어요. 이때 HiveDesk는 동기화를 취소하고 알려 주니, 작업공간 폴더에서 git으로 해결한 뒤 다시 동기화하세요.

## 개발

```bash
git clone https://github.com/TatoGames/Hive-Desk.git
cd Hive-Desk
npm install
npm run dev        # 개발 모드로 실행
npm test           # 핵심 로직 테스트 (가짜 CLI 사용)
```

필요: Node.js 18 이상(권장 22), git.

### 폴더 구조

```
src/
  main/        Electron 메인 프로세스
    hive.ts      작업공간 파일 저장소 (태스크/승인/메시지/메모리/타임라인/실행 기록/사용량)
    activity.ts  CLI 출력 실시간 해석(Claude stream-json, Codex --json, 일반 텍스트)과 진행 상태
    gitdiff.ts   실행 전후 작업 폴더 비교 (임시 index로 만든 tree 비교, 사용자 git 상태는 안 건드림)
    adapters.ts  AI CLI 어댑터 (명령 구성, 실행, 설치 확인, API 키 제거)
    runner.ts    태스크 1건 실행: 승인 → 예산 → CLI → 출력 파싱 → 기록
    engine.ts    설정, 자동 실행, 동기화 타이머, 폴더 잠금, 한도, 회사·카탈로그·적성
    checkpoint.ts 실행 전 상태 저장과 되돌리기 (git 숨은 참조 / 파일 백업)
    failure.ts · limits.ts · secrets.ts · staging.ts · updates.ts  실패 분류, 한도 감지, 민감 파일, 첨부 복사, 업데이트 확인
    sync.ts      git 기반 팀 공유
    external.ts  외부 연결: 권한 표, 실행별 허용 도구·MCP 설정, 실시간 결재, 기록
    github.ts · githubflow.ts  gh/git 호출, 업무 브랜치·커밋·PR·CI·리뷰·이슈 흐름
    mcp.ts · webread.ts  MCP 도구 목록 읽기(stdio/HTTP), 웹페이지를 글로 바꿔 첨부
  preload/     렌더러에 안전한 API(window.hive)만 노출
  renderer/    React UI (보드·태스크 상세, 에이전트, 메시지·메모리, 승인, 설정)
  shared/      공용 타입, 모델 카탈로그(models.default.json), 템플릿·배치 규칙·적성 계산
test/          vitest 테스트 + 가짜 CLI
```

### 새 버전 배포하기

1. `package.json`의 `version`을 올려요 (예: `0.2.0`).
2. 커밋 후 같은 버전의 태그를 푸시해요.
   ```bash
   git tag v0.2.0
   git push origin v0.2.0
   ```
3. GitHub Actions(`Release` 워크플로)가 macOS·Windows·Linux 설치 파일을 만들어 Releases에 올려요.

## 한계와 계획

- 에이전트는 비대화형 모드로 돌아가요. 대화는 '자료 요청 → 답변 → 이어서 실행'과 '추가 지시'로 이어져요.
- CLI별 지원 범위가 달라요.

  | | Claude Code | Codex | Antigravity / 직접 입력 |
  |---|---|---|---|
  | 활동 피드 | 구조화(stream-json) | 구조화(`--json`, 실제 CLI로는 미검증) | 출력 텍스트 기반 |
  | 권한 단계 | 도구 허용/차단으로 강제 | 샌드박스로 강제(명령 실행은 danger-full-access) | 프롬프트로만 안내 |
  | 참고 폴더 | `--add-dir` + 그 경로 쓰기 차단(읽기 전용) | 경로만 프롬프트로 알림(`--add-dir`는 쓰기까지 열어서 뺐어요. 작업 폴더 밖 읽기는 문서상 가능하지만 실제 CLI로는 미검증) | 프롬프트로만 안내 |
  | 이어서 진행 | 같은 세션(`--resume`) | 이전 내용을 담아 새로 실행 | 이전 내용을 담아 새로 실행 |
- 참고 폴더 경로는 태스크에 저장되지만 컴퓨터마다 경로가 달라서, 없는 컴퓨터에서는 경고만 떠요.

## v5.1: 자동 검사 · 검토 절약

- **자동 검사 먼저**: 작업이 끝나면 앱이 프로젝트의 테스트·타입 검사·린트(package.json 스크립트, pytest, cargo, go)를 직접 돌려요. 실패하면 AI 검토 없이 오류 내용과 함께 담당자에게 바로 돌려보내요. 같은 실패가 반복되면 원래 있던 문제일 수 있어 검토자가 판단해요.
- **앱 실행 확인**: Electron 앱이면 빌드 후 직접 띄워서 처리되지 않은 오류와 바로 꺼지는지를 보고, 첫 화면을 찍어 검토자에게 보여 줘요.
- **필요할 때만 AI 검토**: 작고 안전한 변경이 검사를 통과하면 AI 검토를 생략해요. 민감한 파일(로그인·토큰·결제·설정·배포), 많이 지우는 변경, 큰 변경은 언제나 검토해요. 검토자는 diff와 검사 결과를 받고 검사를 다시 돌리지 않아요.
- **돌려보내기 상한**: 1~3번 (기본 2번), 넘으면 윗 직책에게 올려요.
- **긴 명령 시간 초과 완화**: 설치·빌드·테스트 명령이 조용히 도는 동안에는 응답 없음으로 끊지 않아요 (최대 20분).
- 설정 › 자동 검사와 AI 검토에서 바꿀 수 있어요.

## v0.6: 쉬운 시작 · 화면 정리

- **시작하기 화면**: AI 로그인 → 팀 꾸리기 → 첫 일 맡기기 3단계. 다 하면 메뉴에서 사라져요.
- **한 번에 팀 꾸리기**: 템플릿을 고르면 조직도를 만들고, 연결된 AI로 모든 자리를 채워요 (계획·검토는 강한 모델, 구현은 실속 모델, 검토자는 다른 모델).
- **팀 저장·불러오기**: 조직도와 직원 구성을 저장해 두고 다른 회사에서 그대로 꾸려요. 다른 회사 직원을 골라 데려올 수도 있어요.
- **같은 이름 직원**: 이름이 겹치면 기존 직원을 덮어쓰지 않고 "이름 2"로 새로 만들어요.
- **메뉴 정리**: 일 · 팀 · 더보기로 묶었어요. 새로 시작하면 매일 쓰는 메뉴만 보이는 기본 모드, 사이드바의 "고급 메뉴 보기"로 전부 볼 수 있어요. 숨긴 메뉴도 기다리는 일이 있으면 보여요.
- **내가 할 일**: 결재·자료 요청·결과 확인에 더해 실패한 업무, 최종 보고서, 위원회 안건, 협업 요청, 한도 대기, 로그인 필요를 한곳에 모아 보여 줘요.
- **결과 카드**: 끝난 업무 상세 맨 위에 한 일, 확인 방법, 바뀐 파일, 자동 검사, 검토 결과, 남은 위험, 되돌리기를 모았어요.
- **화면 도움말**: 화면마다 처음 한 번 안내가 뜨고, 어려운 말 옆 ? 를 누르면 쉬운 설명이 나와요. 설정 › 도움말에서 용어 풀이와 안내 다시 보기.

## v0.6.1: 같은 폴더 동시 작업 · 토큰 절약

- **같은 폴더 동시 실행**: git 폴더에서 다른 업무가 이미 돌고 있으면 단독 업무도 자기 작업 폴더(`.hive-worktrees`)에서 동시에 돌고, 끝나면 자동으로 합쳐요. 폴더 대기 카드에 이유와 **git 폴더로 만들고 병렬 켜기** 버튼(확인 후 `git init`)이 나와요. 설치된 패키지(`node_modules`)는 원래 폴더 것을 연결해서 써요.
- **시작하기에서 작업 폴더 고르기**, Electron 폴더는 시작 규칙 자동 적용, 프로젝트에서 규칙 불러오기(Electron · 웹 · 파이썬).
- **프로젝트 요약**: 폴더 구조·스크립트·README·최근 끝낸 일을 앱이 만들어 프롬프트에 넣어요(토큰 0).
- **묶음 검토 한 번에**: 큰 일의 하위 작업은 통합 뒤 한 번에 교차 검토해요(위험한 변경은 따로).
- **비용·시간 표시**: 업무 상세에 단계별 AI 실행 횟수와 시간, 자동 검사 시간, 생략한 AI 검토 수.
- [사용법 가이드](docs/guide.md)에 화면 이미지를 넣었어요.
