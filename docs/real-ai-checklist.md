# 릴리스 전 실제 AI 점검 (자동 테스트는 가짜 AI로만 돌아요)

경량 모델로 최소 시나리오를 한 번씩 돌려 보고 릴리스하세요. 사용량은 조금 들어요.

1. **연결 확인**: 설정/에이전트에서 사용하는 CLI마다 [연결 확인]. 성공하면 에이전트 카드에 확인 시각이 보여야 해요.
2. **모델 목록**: 회사 탭 → 모델 카탈로그 → [agy 계정 모델 불러오기]. 계정이 쓸 수 있는 모델이 "확인됨"으로 나와야 해요. 안 되면 `agy models` 출력 형식을 알려 주세요.
3. **agy 모델 지정**: agy 에이전트에 모델을 고르고 작은 태스크 1건 실행 → 실제로 그 모델이 쓰였는지 확인.
4. **2단계 위임 1건**: 경량 모델(Haiku/Flash 등)로 만든 작은 회사(총괄 → 팀장 → 직원 1명)에 "README에 한 줄 추가" 같은 일을 위임. 계획 `[[SUBTASK…]]`, 교차 검토 `[[VERDICT…]]`, 통합, 최종 보고서까지 이어지는지 확인.
5. **CEO 안건 1건**: CEO 자리 에이전트 2명 이상으로 간단한 안건을 올려 제안 → 비판 → 투표(`[[VOTE…]]`) → 이사회 결정이 되는지 확인.
6. 형식을 못 지키는 모델이 있으면 어느 모델이 어떤 표시를 틀렸는지 기록해 두세요 (프롬프트 보강 근거).

## v4 추가 점검 (멈춤·실시간 조정)
7. **실행 중 지시(바로 반영)**: Claude 에이전트에 숫자를 천천히 세는 업무를 시키고, 도는 중에 "보고서 맨 앞에 BANANA를 적어줘"를 `바로 반영`으로 보내요. 지시 목록이 `전달됨 → 확인함`(AI가 [[ACK]]를 쓰면 `반영됨`)으로 바뀌고 결과에 반영됐는지 확인.
8. **일시 정지 → 지시 → 이어서**: 도는 업무에서 ⏯ 일시 정지 → 상태가 `일시 정지됨`으로 바뀌고 AI가 멈추는지, `지시하고 이어서`로 같은 대화에서 이어지는지 확인. 정지 중에 20분 이상 두어도 무활동으로 끊기지 않아야 해요.
9. **즉시 끊고**: `즉시 끊고`로 지시하면 하던 도구 호출이 중단되고 새 지시를 따르는지 확인. 중단된 실행이 실패로 남지 않아야 해요.
10. **트리 취소가 재시작되지 않는지**: 위임 업무를 만들어 하위 작업이 돌 때 ✕ 취소(아래 업무 전체) → 모든 실행이 멈추고 10분 뒤에도 저절로 시작하는 업무가 없어야 해요. 비상 정지(트레이)도 같은 방식으로 확인.
11. **Codex 등 실시간 입력이 없는 연결**: `즉시 끊고`가 "끊고 요약과 함께 다시 시작"으로 동작하는지(Codex의 `exec resume`은 이 환경에서 확인하지 못했어요) 확인.
12. **프로세스 정리**: 중지 후 `ps`로 claude/codex 프로세스가 남지 않았는지(Windows는 작업 관리자) 확인.


## v4 추가 점검 (외부 연결 · 6-4 ~ 6-7)
자동 테스트는 가짜 CLI로 권한 요청 흐름을 확인했어요. 실제 Claude Code에서 아래를 꼭 한 번 확인하세요.

13. **실시간 결재(가장 중요)**: 외부 연결 탭에서 웹 연결을 만들고 웹페이지 읽기만 켜고(허용 사이트는 비워 둠) Claude 직원에게 `읽기`를 줘요. "https://example.com 을 읽고 한 줄 요약" 업무를 실행하면 결재함에 `외부 연결 · 실시간 결재`가 올라오고, 승인하면 그 실행이 이어서 끝나야 해요. 거절하면 AI가 이유를 받고 계속 진행해야 해요. (`--permission-prompt-tool stdio`와 시작할 때 보내는 `initialize` 요청이 이 CLI 버전에서 받아들여지는지 확인하는 단계예요. 실패하면 실행 기록의 stderr를 알려 주세요.)
14. **허용 사이트**: 위에서 [항상 허용]을 고르면 같은 사이트는 다음부터 묻지 않아야 해요. 보고서 파일에 `참고한 출처`가 남는지 확인.
15. **웹 기본 꺼짐**: 웹 연결 권한이 없는 직원이 웹을 읽으려 하면 거부되는지 확인.
16. **MCP(토큰 방식 1개)**: Notion 또는 Slack을 토큰으로 연결 → [도구 목록 읽기]가 도구를 읽기/쓰기로 나누는지 확인 → `쓰기(결재)` 직원이 쓰기 도구를 부르면 결재가 오고, [고쳐서 승인]한 내용대로 보내지는지 확인. 실행이 끝난 뒤 `.local/mcp/`에 실행용 설정 파일이 남지 않아야 해요.
17. **GitHub**: gh가 없는 컴퓨터에서 외부 연결 탭 [GitHub CLI 설치] → [GitHub 로그인](브라우저) → [로그인 확인]이 `로그인됨`이 되는지 (macOS·Windows 각각). 그다음 테스트 저장소를 프로젝트에 지정 → 업무 1건 실행 → `hive/…` 브랜치에 커밋 → 사람 확인 → PR 생성 → PR에 리뷰 댓글을 달고 [지금 GitHub 확인] → 업무에 지시로 들어오고 다시 실행돼 같은 PR에 커밋이 올라가는지 → CI 통과 뒤 [머지]까지 확인. main에는 직접 올라가지 않아야 해요.
18. **실행 중 메시지(6-4)**: Claude 직원이 도는 동안 메시지함에서 그 직원에게 메시지를 보내면 활동 피드에 바로 반영되는지 확인.
