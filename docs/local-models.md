# 내 PC AI: 실측 방법과 후보 정리

이 문서는 v6 8-1(실측 도구·후보 정리)의 결과물이에요. **모델 이름·크기·라이선스는 아직 확인하지 않았고**, 이 문서를 쓴 환경에는 로컬 엔진이 없어서 실제로 돌려 보지 못했어요. 아래 수치와 후보는 모두 "예시"이고, 사용자 PC에서 앱의 실측으로 채워요.

## 앱에서 재는 방법
1. **AI 연결 › 내 PC AI**에서 Ollama(또는 LM Studio) 주소를 연결해요.
2. 모델 옆 **속도 재기**: 짧은 답 두 번으로 *불러오는 시간*, *첫 글자까지*, *초당 토큰*을 재요. 결과가 있으면 추천 등급이 사양 추정 대신 실측으로 정해져요(초당 4토큰 미만 → 경량, 10토큰 미만이면 최상위를 균형으로 낮춤).
3. **실측(10개)**: 작은 수정 10개(버그 고치기·함수 만들기·이름 바꾸기 등)를 시켜요. 앱이 파일을 주고, 모델은 **고친 파일 전체**를 돌려주고, 앱이 검사(Node)로 통과 여부를 확인해요. 모델이 도구를 다룰 필요가 없는 "앱이 이끄는 수정 방식"(v6 4-5)이에요. 결과(통과 수·시간)는 모델별로 저장돼요.
4. 이 결과로 정할 것: 어느 등급 후보를 기본으로 둘지, 로컬이 맡을 일의 범위(`쉬운 일만`), 앱이 이끄는 방식이 충분한지.

실측 항목은 `src/shared/bench.ts`(`BENCH_TASKS`)에 있어요. 모든 항목은 모범 답안이 통과하고 시작 파일이 실패하는 것을 테스트로 확인했어요.

## 후보 목록(데이터 파일)
- 내장: `src/shared/local-models.default.json`. 앱 설정 폴더에 `local-models.json`을 두면 그 목록이 내장 목록 대신 쓰여요(앱 업데이트 없이 갱신).
- 형식: `{ "updatedAt": "...", "models": [{ "id": "<Ollama 이름>", "label", "paramsB", "tier", "approxGB", "kind", "tags", "licenseName", "licenseUrl", "licenseStatus": "checked|unchecked", "note" }] }`
- `kind`: `text`(기본) / `embedding` / `vision` / `other`. `text`가 아니거나 `검색용` 태그가 있으면 화면에서 기본으로 숨겨요("검색용·사진 전용도 보기"를 켜면 보여요). 없는 값은 `text`예요.
- `tags`: 파일에 적는 태그는 능력(`도구 호출`, `생각하며 풀기`, `사진 보기`, `검색용`), 용도(`코딩`, `일반`, `번역·다국어`, `짧은 대화`, `긴 글`), 주의(`라이선스 확인 전`, `영어 위주`, `오래된 모델`)뿐이에요. 다른 글자는 버려요. `경량/균형/상위`(용량 기준), `잘 맞아요/빠듯해요/이 PC엔 무거워요`(이 PC), `설치됨`, `추천`은 앱이 계산하니 적지 않아요.
- `approxGB`는 모델 카드에서 읽은 값만 적어요. 읽지 못했으면 비워 두면 화면에 "용량 미확인"으로 나와요.
- `추천`은 이 PC에서 `잘 맞아요`이고 `코딩`/`일반` 태그가 있고, 앱의 실측(10개)에서 7개 이상 통과한 모델에만 붙어요. 실측 전에는 "추천 후보"예요. `도구 호출` 태그가 없으면 "쉬운 일만 범위에서만 직원으로 쓸 수 있어요"가 보여요.
- 목록 갱신 방법: `local-models.json`(설정 폴더)에 위 형식으로 모델을 적고, 모델 카드(ollama.com/library/<이름>)에서 용량·라이선스를 읽어 채운 뒤 `updatedAt`을 바꿔요. 새 모델은 `licenseStatus`를 `unchecked`로 두고 `라이선스 확인 전` 태그를 달아요.
- 지금 내장 후보는 **모두 `unchecked`**: 이름은 공개된 Ollama 라이브러리에서 흔히 쓰는 것을 적은 예시이고, 라이선스 조건은 앱이 확인하지 않았어요. 그래서(내장 22개 중 18개는 용량·라이선스 이름을 아직 모델 카드에서 읽지 못해 비워 뒀어요) 화면에서 "라이선스 확인 전"으로 표시하고, 설치 전에 사용자가 조건을 직접 확인했다는 체크를 해야 버튼이 켜져요.
- 상용 배포(앱에 모델을 포함하거나 추천 목록에 "확인됨"으로 올리는 것)를 하려면 모델마다 라이선스 원문을 읽고 `checked`로 바꾼 뒤에 해요.
